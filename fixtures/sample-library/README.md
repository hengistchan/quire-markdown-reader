# Quire sample libraries

These localized Markdown workspaces are the source content for the Chrome Web Store screenshots.

- Open `en/` in Quire to inspect the global English sample library.
- Open `zh-CN/` in Quire to inspect the Simplified Chinese sample library.
- Keep both libraries structurally aligned when adding or removing sample documents.

Run `npm run store:assets` after changing the fixtures, then run `npm run store:verify` to validate the generated screenshots.

# Store artwork

Release artwork is generated from the versioned Quire interface and brand source.

- `screenshot-reader.png`: 1280×800 primary store screenshot
- `screenshot-workspace.png`: 1280×800 workspace and nested-tree screenshot
- `screenshot-settings.png`: 1280×800 settings and bilingual experience screenshot
- `promo-small.png`: 440×280 text-free Chrome Web Store promotional tile
- `icon-128.png`: 128×128 store icon

The screenshots must show the tagged build without private documents, account information, or browser profile data.

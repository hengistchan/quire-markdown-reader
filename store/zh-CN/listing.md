# Quire — Markdown 阅读器

## 简短说明

安静、私密的本地与网络 Markdown 文档阅读工作区。

## 单一用途

Quire 将用户选择的本地文件、文件夹、当前页面文本或网络 Markdown 地址渲染成专注、只读的阅读工作区。

## 完整说明

阅读 Markdown，不必再打开一个编辑器。

Quire 可以打开单个 Markdown 文件，也能连接本地文件夹并显示真正的嵌套文档树。工作区内的图片与 Markdown 链接会正确解析；在浏览器支持时，文件修改后会自动刷新。你也可以输入网络 Markdown 地址，并只向该网站授予访问权限。

阅读器包含文档搜索、大纲导航、阅读进度、明暗主题、排版设置、代码高亮、任务列表、脚注、提示块、KaTeX、Mermaid、安全 HTML 和自定义文档 CSS，并支持英文与简体中文。

点击工具栏按钮、按下 `Alt/Option + Shift + M`，或使用页面右键菜单，即可把当前页面的可见文本带入阅读器。

隐私是产品边界的一部分：Quire 没有账号、统计、广告、追踪或开发者后端。本地文档保留在设备上，Quire 永远不会修改源文件。

## 权限说明

- 当前标签页与脚本：仅在用户明确操作后导入当前页面的可见文本。
- 右键菜单：提供“使用 Quire 打开”。
- 本地存储：保存阅读设置、引导状态、最近记录与工作区恢复信息。
- 可选网站访问：仅从用户选择的网站读取远程 Markdown 文档。

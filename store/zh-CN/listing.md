# Quire — Markdown 阅读器

## 简短说明

在浏览器中专注阅读本地文件夹、单个文件和网络上的 Markdown；无需账号，不上传文档，也不修改源文件。

## 单一用途

Quire 将用户选择的本地文件、文件夹、当前页面文本或网络 Markdown 地址渲染成专注、只读的阅读工作区。

## 完整说明

把 Markdown 从“源码”变成真正适合阅读的文档。

Quire 的用途很简单：在 Chrome 中打开本地或网络 Markdown，并提供一个专注、只读的文档工作区。它适合阅读项目说明、开发文档、知识库、课程笔记和长篇技术文章，让你不必为了查看格式化内容而启动编辑器，也不必把私人文件上传到在线服务。

主要功能：

- 打开单个 .md、.markdown 或 .mdx 文件
- 开启本地文件网址访问后，直接预览 Markdown 绝对路径，并在地址栏保留原始路径
- 连接本地文件夹，并在真实的嵌套文件树中浏览文档
- 在文件树和当前文档大纲之间快速切换
- 正确解析工作区内的相对图片与 Markdown 链接
- 搜索当前文档，并显示阅读进度
- 调整明暗主题、字体、字号、行高和页面宽度
- 渲染代码高亮、任务列表、脚注、提示块、KaTeX 公式和 Mermaid 图表
- 输入网络 Markdown 地址，仅向你选择的网站请求访问权限
- 通过工具栏、右键菜单或 `Alt/Option + Shift + M` 导入当前页面的可见文本

为什么安装 Quire？

它把“查看 Markdown”与“编辑 Markdown”分开：阅读界面保持安静，源文件始终只读，本地文档保留在设备上。对经常阅读 README、技术规范、研究笔记或本地知识库的人来说，这意味着更少的界面干扰、更清晰的导航，也不需要改变现有的文件组织方式。

Quire 是开源软件。它没有账号、统计、广告、追踪或开发者后端；本地文档不会上传，源文件不会被修改。

## 权限说明

- 当前标签页与脚本：仅在用户明确操作后导入当前页面的可见文本。
- 右键菜单：提供“使用 Quire 打开”。
- 本地存储：在当前设备保存阅读设置、引导状态和最近记录。
- 可选网站访问：仅从用户选择的网站读取远程 Markdown 文档。
- 本地文件网址访问：仅在你从 Chrome 扩展详情页主动开启后，识别并读取你在地址栏明确打开的本地 .md、.markdown 或 .mdx 文档。
